# ユーザーフロー

## 営業導線フロー

```
[流入] → [LP] → [無料診断フォーム] → [サンクス画面]
                                           ↓
                                    [リード作成 + 初期スコア]
                                           ↓
                                    [メールシーケンス開始]
                                           ↓
                              [追客メール Day 0, 2, 5, 8, 12, 16, 21]
                                           ↓
                                    [商談予約ページへ誘導]
                                           ↓
                                    [予約完了 → booked]
                                           ↓
                                    [商談実施 → proposal/won/lost]
```

## 画面遷移

### 公開ページ
```
/ (LP)
  ├── CTAクリック → /diagnosis
  └── ヘッダー → /diagnosis

/diagnosis (無料診断フォーム)
  └── 送信成功 → /thanks?lead_id=xxx

/thanks (サンクスページ)
  └── 予約ボタン → /book?lead_id=xxx

/book (商談予約)
  └── Calendly or 簡易フォーム
```

### 管理画面
```
/admin/login (ログイン)
  └── 認証成功 → /admin

/admin (ダッシュボード)
  ├── リード一覧 → /admin/leads
  └── 個別リード → /admin/leads/[id]

/admin/leads (リード一覧)
  └── 行クリック → /admin/leads/[id]

/admin/leads/[id] (リード詳細)
  ├── ステータス変更
  ├── イベント履歴
  ├── メール送信履歴
  └── 予約情報
```

## ステータス遷移

```
new → contacted → engaged → booked → proposal → won
                                              └→ lost
（どの段階からでも lost に遷移可能）
```

## スコアリングイベント

| イベント | スコア |
|----------|--------|
| フォーム送信 | +10 |
| 緊急度「すぐ」 | +10 |
| 従業員数 5-30 | +5 |
| メールリンククリック | +5 |
| 予約ページ訪問 | +10 |
| 商談予約完了 | +20 |
