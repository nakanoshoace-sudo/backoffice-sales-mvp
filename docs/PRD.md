# PRD: オンラインバックオフィス代行 営業自動化MVP

## 概要

小規模〜中小企業（従業員5〜30名）向けに、バックオフィス業務のオンライン代行サービスを提供する事業の営業導線MVPを構築する。

## 目的

- 最短で仮説検証し、実際に商談を生む
- 月額契約につなげる営業導線を半自動化する
- 「見込み客獲得 → 無料診断 → 追客 → 商談予約 → 営業管理」を一気通貫で回す

## サービス概要

| 項目 | 内容 |
|------|------|
| サービス名 | オンラインバックオフィス代行 |
| 提供価値 | 経理・請求・データ入力・秘書・総務等のオンライン代行 |
| 契約形態 | 月額契約 |

### 料金プラン

| プラン | 月額 |
|--------|------|
| ライト | 8万円 |
| スタンダード | 15万円 |
| プレミアム | 30万円 |

## ターゲット顧客

- 従業員 5〜30名の中小企業
- 管理部門が弱い / 属人化している
- 社長が事務に追われている
- 採用コストを抑えたい
- IT / Web / 士業 / コンサル / EC / 受託会社

## MVP範囲

### 含むもの
1. サービスLP
2. 無料診断フォーム + サンクス画面
3. リード保存・管理画面
4. 営業ステータス管理
5. メールシーケンス（テンプレートベース）
6. 商談予約導線
7. ダッシュボード
8. ドキュメント一式

### 含まないもの（後回し）
- 複雑な権限管理
- 請求書発行の自動化
- 高度な会計システム連携
- AIパーソナライズ文面
- SNS/DM/電話の自動化
- マイクロサービス分割
- ABテスト基盤
- 多言語対応
- ネイティブアプリ

## KPI仮説

| 指標 | 目標 |
|------|------|
| LP訪問 → フォーム送信率 | 5-10% |
| フォーム送信 → 商談予約率 | 20-30% |
| 商談予約 → 成約率 | 30-50% |
| 月次リード数 | 20-50件 |
| 月次予約数 | 5-15件 |
| 月次won数 | 2-5件 |

## リスク

| リスク | 対策 |
|--------|------|
| フォーム送信率が低い | LPコピーの改善、CTA位置調整 |
| メール開封率が低い | 件名テスト、送信タイミング調整 |
| 商談に至らない | スコアリング閾値調整、追客内容改善 |
| リードの質が低い | フォーム設問の調整、ターゲティング改善 |

## 完了条件

- LPが表示される
- 無料診断フォームからリードが作成される
- サンクス画面に遷移する
- 管理画面でリードが見られる
- ステータス更新ができる
- スコアが見える
- イベント履歴が見える
- メール送信導線がある
- 商談予約導線がある
- booking状態が残せる
- README/docsがあり再現可能
- seedでデモができる
